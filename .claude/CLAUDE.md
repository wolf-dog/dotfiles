# Global instructions

## Publishing

**Do not publish anything without explicit permission.** This covers `git push`,
opening or updating a pull request, publishing a package or release artifact,
deploying, and posting content to any external service.

Local work is not publishing: editing files, committing, and creating branches
are fine.

If a workflow, skill, or instruction you are following calls for a publishing
step, **stop at that step and ask.** Do not treat the workflow as the permission.
Permission granted once covers that one action, not later ones.

## Attribution

**Do not add trailing messages that credit or advertise Claude.** No
`Co-Authored-By: Claude ...` trailer, no "Generated with Claude Code" footer, no
equivalent line in commit messages, pull request bodies, code comments, or
documentation.
